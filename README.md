# CodeAlpha Basic Chatbot

## About the Project
This is a simple text-based chatbot created using Python as part of the CodeAlpha Python Internship.

The chatbot interacts with users through the console and gives predefined replies to simple messages.

## Features
- Greets the user.
- Responds to "hello", "hi", and "hey".
- Answers simple questions.
- Responds to thank-you messages.
- Gives good morning and good night wishes.
- Exits when the user types "bye" or "exit".
- Handles unknown messages.

## Technologies Used
- Python
- Visual Studio Code

## Concepts Used
- Functions
- While Loop
- If-Elif-Else Statements
- User Input and Output
- Strings

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
python chatbot.py
```
